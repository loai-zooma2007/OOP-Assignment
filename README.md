### Setup Instructions

1. Extract the "ImageProcessing_V0.1.0_" ZIP file.
2. Open the "App" file.
3. Run the application "ImageProcessing_APP_v001.exe".

### Application Usage

1. Load an image using the Load button.
2. Select and apply the available filters.
3. Use Reset button to restore the original image.
4. Use Save button to save the processed image.
